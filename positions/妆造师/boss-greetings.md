## Greeting A

```
Hi 你好呀！很高兴认识！方便的话，请您快速让我们了解一下您的情况！
1. 麻烦发一份完整简历（包完整教育和工作经历）
2. 简单介绍一下相关工作 / 手工经验，有作品集或照片也可以一起发来。
3. 目前是否在花桥本地，通勤是否方便？
4. 是否喜欢手工制作，能接受细致、重复的工作，并愿意耐心学习？
5. 大概什么时候可以到岗？
```

## In-Person Interview Instructions

```
【面试说明】
· 关于面试：本次为「妆造实践」面试，主要用于招聘评估。现场会先进行一段简单培训，再由你实际动手操作。无需有 Kigurumi 制作经验，也无需提前准备材料。主要考察学习能力、动手能力、细致程度，以及能否根据参考图和操作步骤完成制作，不要求第一次就做到很熟练。
· 关于实践：现场使用的是面试练习材料，不会用于正式订单或商品交付，也不会收取任何培训费、材料费或其他费用。现场可能会有多名同学一起参加面试，一般不超过 5 人。
· 关于时间：整个面试预计约 60-120 分钟，请尽量预留充足时间。如临时有事、可能迟到或无法参加，请提前通过 BOSS 直聘联系我们。
· 关于穿着：我们不限制着装。现场会使用色粉、颜料、胶水等手工材料，建议穿方便活动、不怕轻微弄脏的衣服。如对颜料、胶水、酒精等常见材料敏感，也可以提前告知我们。
· 关于提前了解：你可以通过抖音、小红书搜索「Kigurumi」了解我们制作的产品，也可以搜索「BJD 妆造」「BJD 化妆教程」等内容，提前了解类似的基础工艺。我们的实际制作流程已经进行了较多标准化和工具化，现场也会提供对应素材、工具和操作规范，无需提前学习或掌握。
· 关于地点：楼体东侧有电梯，乘电梯上 3 楼即可，3 楼一整层都是我们的工作区域。
· 关于沟通：面试时间、参加方式以 BOSS 直聘平台发送的正式邀请为准。面试结果及后续安排也会统一通过 BOSS 直聘沟通。
---
我们可以先加个微信，具体信息我们在微信通过 笔记 分享给您！
```
