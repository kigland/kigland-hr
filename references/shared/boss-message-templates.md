# BOSS直聘 Message Templates（通用）

Source: Feishu Wiki `HZwIwBImJi4EvckYVMAcWTlHnMh`

岗位无关的通用话术。各岗位专属开场白与面试说明见 `positions/<岗位>/boss-greetings.md`。

## Repeat Inquiry

```
Hi 您好，
我们看到后台咱们之前已经联系过我们的同事啦～
为了避免重复沟通、信息不一致，后续您直接在原来的沟通窗口继续联系就可以。感谢理解～
```

## Online Interview Invitation

```
Hi 
咱们是否方便 XXX 约个线上面试，大概 20 ~ 30min。
主要考察沟通、逻辑、协作能力。
如果可以，我们将会安排飞书会议链接，通过 BOSS 直聘完成预约，到时候通过飞书 App 介入会议。
```

## In-Person Interview Invitation

```
Hi 
咱们是否方便 XXX 约个线下面试，大概 60 ~ 120 min。
主要考察实施、实践能力。如果可以通过 BOSS 直聘完成预约。稍后将会同步您一段面试说明
```

## Online Interview Calendar Note

```
本次线上面试主要了解您的沟通表达、基本协作能力及岗位匹配情况。面试中会安排简单的信息检索、文档操作，也会了解您的社会常识和问题处理方式。同时，我们也会交流部分个人经历、工作习惯与价值观相关问题。
```

## Communication Questions

1. 您目前主要的学习渠道、来源有什么？
2. 请你评价一下 AI 人工智能应用对你的行业带来影响？
3. 如果需要设计一个长期学习的机制您会怎样设想？如果执行不了的话您会如何补救。
4. 您的父母从事哪些行业？你认为在成长过程中，会有怎样的影响？
5. 分享一件过去工作中难以忘记的事情？为什么让你难忘？
6. 你遇到过的最大的挫折挑战是什么？
7. 如果给你每月两万月（或 4 倍于您的工资）其中一部分可以是您的工资，你都会做到什么？如何规划？
8. 请讲述一下上一份工作中，你最关注哪些指标？如何达成？
9. 你觉得有哪些别人很认同的观点但是你不认同的？
10. 请描述一次你打破常规并付诸实践的经历？
